# 补出来「发糊」的分频带实测结论

> 起因：用户反馈「效果真的不太好，有些糊」。
> 本文记录从「以为是缺颗粒」到「实测确认是低频结构被压平」的完整过程与数据。
> 测试日期 2026-09-25，CleanPlate v0.02。

---

## 1. 最初的假设（错的）

看到「补全区域像磨过皮」这个描述，第一反应是**高频缺失**——
LaMa 输出的补全区缺少照片本身的颗粒/噪点，跟周围质感对不上，
所以显得假。于是写了一版**颗粒再注入**（`app/grain.py`）：

1. 从选区外围一圈「环带」统计局部标准差，估出周围质感
2. 从选区外随机抠小 patch 作为颗粒种子（用真实颗粒而不是生成白噪声）
3. 铺进补全区，用闭环迭代把选区内的局部标准差调到目标值
4. 强度滑块控制「填到周围质感的百分之多少」

这个实现本身是**工作正常**的：闭环让强度语义变得线性可预测
（强度 0.6 真的达成 60%，1.0 达成 100%，2.0 达成 201%），
选区外 bit 级不变的不变式也守住了。

**但它在真实照片上几乎没效果。** 这才是问题。

---

## 2. 真实照片上的异常

用 4648×7502 的真实照片（人像 + 户外背景）测试，选区放在画面中部：

| 强度 | 选区内局部标准差 | 达周围质感 |
|---|---|---|
| 0.0 | 0.00747 | 118% |
| 0.3 | 0.00747 | 118% |
| 0.6 | 0.00747 | 118% |
| 1.0 | 0.00747 | 118% |
| 1.5 | 0.01104 | 175% |

**0.0 到 1.0 完全没变化。** 原因是 LaMa 补出来的区域（σ=0.0075）
已经比周围真实质感（σ=0.0063）更粗糙了 —— 所以「补齐到邻居水平」
这个逻辑判定不需要补，自动跳过了。

> 这暴露了语义设计的问题：「补齐到邻居水平」听起来合理，
> 但实际变成了「有时灵有时不灵」的自动判断，用户拧滑块没有反馈。
> 这是**行为**问题，不是 bug。

---

## 3. 换五个位置重新测

怀疑是选的位置特殊，于是在五个不同区域各跑一遍，
测「原图该处的质感」vs「LaMa 补完的质感」：

| 区域 | 尺寸 | 原图 σ | 补完 σ | 保留率 | 周围环带 σ |
|---|---|---|---|---|---|
| A 天空/围栏区 | 1486×1500 | 0.00740 | 0.00648 | 88% | 0.00619 |
| B 左侧天空 | 928×1200 | 0.00367 | 0.00444 | **121%** | 0.00400 |
| C 右上角 | 928×1050 | 0.00376 | 0.00380 | 101% | 0.00415 |
| D 下方地面 | 1394×900 | 0.00780 | 0.00625 | **80%** | 0.00686 |
| E 中部偏左 | 1114×1200 | 0.00692 | 0.00750 | 108% | 0.00670 |

**结论：颗粒层面的保留率是 80%~121%。** 也就是说，
**LaMa 在纹理/颗粒这一层基本没丢东西**，有些区域补出来甚至比原图还「粗糙」。

到这里，最初的假设已经被证伪了 —— 往这个频带里加能量是打错靶子。

---

## 4. 真正的原因：分频带拆解

既然颗粒不是问题，那就把补全区按频带拆开，逐带对比原图同一位置。

用两个高斯模糊的差做出各个频带，取补全区内的中位数：

| 频带 | 原图 | 补完 | 保留率 |
|---|---|---|---|
| **低频（结构 / 明暗）** | 2.870 | 1.562 | **54%** |
| 中低频（大纹理） | 0.608 | 0.602 | 99% |
| 中频（纹理细节） | 0.598 | 0.619 | 104% |
| 中高频（细纹） | 0.921 | 0.780 | 85% |
| 高频（颗粒） | 0.521 | 0.423 | 81% |

补充两项：

- **边缘锐度**（Laplacian 绝对中位数）：原图 4.000 → 补完 3.000，**保留 75%**
- **局部对比度**（win=9 的 σ 分布，90 分位）：原图 0.0160 → 补完 0.0110，**保留 69%**

### 读法

**掉得最多的是低频（54%），中高频以上反而都在 80% 以上。**
局部对比度的 90 分位只剩 69%，意味着「原本有起伏、有层次的那些位置」
被抹成了均匀的一片。

人眼把这个读作「糊」—— 但它的物理成因不是「缺细节」，而是
**「大片区域被补成了接近纯色 / 线性渐变，失去了明暗层次」**。

这是 LaMa 的**固有能力边界**：给定一个大的空洞，它没有足够信息去重建
那么大的结构，只能沿着边界颜色平滑地插值过去。
所以「大面积会偏柔偏糊」这句话的真正机理在这里。

## 5. 结论与决策

| 项 | 决策 |
|---|---|
| 颗粒再注入（`app/grain.py`） | **默认关闭**（`DEFAULT_GRAIN=0`），保留为手动选项 |
| 保留它的理由 | 应付「补完是一片干净的墙 / 天、看着发干」这一种具体情况仍有用 |
| 关闭它的理由 | 目标频带只掉 19%，投入产出比低；patch 平铺会留块状拼接痕迹；真实图上容易被自动跳过逻辑吃掉，反馈不明确 |
| 颗粒耗时 | 实测 1.6~1.7 秒（4648×7502），占总时间 15~22%，主要开销是闭环迭代里每轮的全图卷积 |

### 想真正改善大面积补全，方向是**结构层**不是纹理层

1. **分更小的区域多次修**（成本最低、当下最有效）
   让模型每次只看一小块，周围上下文相对充足，结构能接上。
2. **结构层补偿**：从邻域取低频结构信息做指引 —— 难度高，容易出伪影。
3. **换专门为「移除」训练的模型**：RORem / FreeCompose / FLUX-ObjectRemoval。
   是治本的方向，但要重做推理封装 + 下几 GB 权重。
   见 `去杂物技术选型与PS插件可行性研究.md`。

## 6. 方法论备忘

这次的教训：**「看起来像 X」不等于「就是 X」**。

「补出来像磨过皮」这个描述强烈暗示高频缺失，直接照着做，
结果在真实数据上几乎无效。拆频带之后才发现问题在低频。

所以下次遇到「画质类」的主观反馈，**第一步应该是量化诊断**
（分频带 + 局部对比度 + 边缘锐度），而不是照着形容词直接实现方案。
`app/grain.py` 这套测量函数（`_local_sigma` / `estimate_grain`）
可以复用做诊断工具。
